# وكيل البريد الدراسي (Study Email Agent)

مشروع التخرج لدورة «رفع الإنتاجية بالذكاء الاصطناعي» (أكاديمية سدايا).

وكيل ذكاء اصطناعي يقرأ رسائل بريد دراسي موسومة، ويصنّفها، ويستخرج المواعيد والإجراءات، ويجهّز **مسودات** ردود فقط. لا يرسل ولا يحذف ولا يفتح روابط، والقرار النهائي للإنسان.

## كيف يعمل
1. أضع وسم `Agent-Study` على الرسائل المراد فرزها.
2. الوكيل يقرأ الرسائل الموسومة فقط.
3. يصنّف كل رسالة (دراسي / فرصة / نشرة / إنجاز) ويستخرج الموعد والإجراء وهل تحتاج ردًا.
4. يجهّز مسودة رد عند الحاجة (لا يرسلها).
5. أراجع النتائج وأقرر.

## النتائج
اختبار على 41 رسالة: الزمن اليدوي ≈ 36 دقيقة، وبالوكيل ≈ 3.5 دقيقة (توفير ≈ 90%). التفاصيل ومنهجية القياس في [measurement.md](measurement.md).
